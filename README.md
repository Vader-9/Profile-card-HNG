<h1>Profile Card - Stage 0</h1>

<p>
This repository contains an accessible and responsive Profile Card created using 
<strong>HTML</strong>, <strong>Vanilla CSS</strong>, and <strong>Vanilla JavaScript</strong>.
</p>

<h2>Project Files</h2>
<ul>
  <li><strong>index.html</strong> – contains the profile card HTML markup (semantic tags + required data-testids)</li>
  <li><strong>style.css</strong> – contains the responsive and accessible styles</li>
  <li><strong>script.js</strong> – updates and displays the current time (milliseconds)</li>
</ul>

<h2>Required Data Test IDs</h2>

  <li>test-user-dislikes</li>
</ul>

<h2>How to Run Locally</h2>
<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/your-username/profile-card.git</code></pre>
  </li>
  <li>Open the project folder:
    <pre><code>cd profile-card</code></pre>
  </li>
  <li>Run the project by double-clicking <strong>index.html</strong> to open in your default browser.</li>
</ol>

<h2>Notes</h2>
<p>No build step required — plain static files only.</p>
